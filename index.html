Concentric Corners

ROUND HANDLES = RADIUS (LINKED) · EDGES = PADDING · SQUARES = RESIZE (CENTERED) · DBL-CLICK = SHARP · LONG-PRESS CORNER = SHAPE







  
No trig. No roots. Just −p

  

    Every corner arc is drawn around a center that sits ρ inward from
    both edges. Pad the box by p and the edges move in by p — so
    keeping the same center simply costs p of radius. With all four
    corners linked, the entire relationship is one subtraction.
  


  

  
Outer as reference — the inner radius is derived, clamped at sharp:

  

    
    
.outer { --r: 48px; --p: 24px;
         border-radius: var(--r); padding: var(--p); }
.inner { border-radius: max(0px, calc(var(--r) - var(--p))); }

  


  
Inner as reference — the outer radius is derived; no clamp needed, adding p only grows it:

  

    
    
.inner { --r: 12px; border-radius: var(--r); }
.outer { --p: 24px; padding: var(--p);
         border-radius: calc(var(--r) + var(--p)); }

  


  

    The clamp is where roundness dies, and it is lossy: once p ≥ ρ the inner
    corner is square, and from a square inner corner the outer radius can only
    be bounded (ρ ≤ p), never recovered. The only square root anywhere is
    decorative — the shared center lies ρ·√2 from the corner along the 45°
    diagonal, a consequence of sitting at (ρ, ρ), never an input.
